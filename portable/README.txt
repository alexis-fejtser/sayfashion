SAY FASHION — ЛОКАЛЬНАЯ ДЕМОНСТРАЦИЯ

1. Распакуйте ZIP-архив в обычную папку.
2. Дважды нажмите «START SHOP.cmd».
3. Магазин автоматически откроется в браузере.
4. Не закрывайте чёрное окно, пока смотрите сайт.
5. Для остановки нажмите ENTER в чёрном окне или запустите «STOP SHOP.cmd».

Магазин: http://127.0.0.1:3210
Админка: http://127.0.0.1:3210/admin
Пароль админки: demo2026

Устанавливать Node.js, npm или базу данных не требуется.

Это демонстрационная копия:
- сервисные ключи из рабочего .env включены по просьбе владельца;
- не передавайте архив посторонним: ключи можно извлечь из файлов;
- реальные заказы не включены;
- bePaid работает в режиме, указанном владельцем при сборке;
- для списка пунктов Европочты требуется интернет;
- изменения товаров сохраняются внутри распакованной папки.

Поддерживается Windows 10/11 x64.
